# 34. ADR 模板

ADR 路径：

```text
docs/adr/ADR-0001-title.md
```

模板：

```markdown
# ADR-0001: 标题

## 状态

Proposed / Accepted / Rejected / Superseded

## 背景

为什么需要这个决策。

## 当前约束

已有架构冻结项、技术限制、产品限制。

## 问题

不做决策会造成什么问题。

## 候选方案

### 方案 A

优点：

缺点：

### 方案 B

优点：

缺点：

## 决策

选择哪个方案，为什么。

## 影响范围

影响哪些模块、文件、文档、测试。

## 迁移计划

如何从当前状态迁移。

## 回滚方案

如果失败如何回滚。

## 后续任务

需要创建哪些 Issue。
```
