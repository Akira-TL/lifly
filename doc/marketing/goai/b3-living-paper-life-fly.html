自动记账之前，
先问一句：这笔是不是已经记过？

手动记录和 Agent 自动记录，不应该变成两套互相不知道的数据。

当前账单导入路径会把新流水与已有 active 账本按方向、金额、发生时间、商户等业务字段比对；所以之前手动记过的交易，也可以在导入时被识别成重复候选。

统一原则：不管来自手动、账单导入还是未来更完整的 AI 记账入口，正式写入前都应该尽可能复用同一套账本去重语义。

识别为 transfer / 中性流水后，不把“资金从一个平台搬到另一个平台”误算成新的消费或收入。疑似重复项进入预览，而不是直接污染账本。

跨平台账单，
不要把同一笔钱算两次。

除了避免“同一笔消费记两次”，Lifly 还要避免把“自己的钱从 A 搬到 B”误算成一笔新消费或收入。

先识别“资金搬家”转账、提现、充值、信用卡还款等中性交易不会直接记成普通收支。
再检查“是不是同一笔”external transaction id、时间、金额、商户、来源、文件 hash + row index 等共同参与重复判断。
最后才确认入账preview → skip / edit → confirm；批次仍可回滚。
