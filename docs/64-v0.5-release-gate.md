## 7. 手动 smoke：导出

导出 metadata：

```bash
curl -X POST "http://127.0.0.1:8310/api/v1/imexport/export" \
  -H "Content-Type: application/json" \
  -d '{"entity_type":"all"}'
```

导出账本 CSV：

```bash
curl -L "http://127.0.0.1:8310/api/v1/imexport/export/stream?entity_type=ledger_transactions" \
  -o lifly-ledger.csv
```

导出备忘 Markdown：

```bash
curl -L "http://127.0.0.1:8310/api/v1/imexport/export/stream?entity_type=memos" \
  -o lifly-memos.md
```

导出全部 JSON：

```bash
curl -L "http://127.0.0.1:8310/api/v1/imexport/export/stream?entity_type=all" \
  -o lifly-all.json
```

## 8. v0.5 已知边界

```text
1. 内部文件上传仍是 upload intent / metadata 基线，不是完整云盘体验。
2. 微信 XLSX 解析覆盖当前真实导出格式，后续微信官方字段变化需补 parser contract。
3. 支付宝 CSV 解析覆盖当前记账本 / 常见账单字段，后续支付宝格式变化需补 parser contract。
4. 导入 commit 只写 ledger_transactions，不自动创建账户 / 分类实体。
5. rollback 是 soft delete，不物理删除 ledger transaction。
6. export 是基础导出，不包含端到端加密、云端打包或增量导出。
7. integration 测试需要手动先启动 API。
```
