# 34. ADR 模板

ADR 文件路径：

```text
docs/adr/ADR-0001-title.md
```

模板：

```markdown
# ADR-0001: 标题

## 状态

Proposed / Accepted / Rejected / Superseded

## 背景

描述为什么需要这个决策。

## 当前约束

列出已有架构冻结项、技术限制、产品限制。

## 问题

说明不做决策会造成什么问题。

## 候选方案

### 方案 A

优点：

缺点：

### 方案 B

优点：

缺点：

## 决策

选择哪个方案，为什么。

## 影响范围

影响哪些模块、文件、文档、测试。

## 迁移计划

如何从当前状态迁移。

## 回滚方案

如果失败如何回滚。

## 后续任务

需要创建哪些 Issue。
```

## ADR 使用规则

以下变更必须走 ADR：

```text
变更技术栈
变更同步策略
新增 MVP 外模块
新增 MCP tool 类别
改变附件存储策略
改变删除/审计/tombstone 规则
改变 Android 不监听通知的隐私边界
改变 Cloud MCP / Local MCP 的职责边界
```

普通功能 PR 不允许偷偷修改架构冻结项。
