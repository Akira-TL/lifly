# 01. 产品定义

## 1. 产品一句话

Lifly 是一个以 AI/MCP 为主要接入方式、以本地优先和云端同步为基础的个人生活数据系统，帮助用户通过自然语言快速记录、整理和查询备忘录、账单和任务提醒。

## 2. 产品不是什么

Lifly 不是传统备忘录 App，不是单纯记账 App，也不是完整日历 App。它不是以“打开软件填写表单”为第一体验，而是以“用户和 AI 说一句话，系统自动落库”为核心体验。

## 3. 目标用户

MVP 阶段主要面向：

- 有较强数字化记录习惯的个人用户；
- 经常使用 AI 工具的开发者、研究生、独立创作者；
- 希望在 QQ/微信/Hermes/OpenClaw 等入口中完成生活记录的人；
- 需要本地可用、云端同步、可导出数据的人。

## 4. 核心痛点

传统生活管理软件的问题：

1. 打开软件成本高；
2. 记录入口分散；
3. 记账、备忘、任务、日程互相割裂；
4. AI 接入通常只是“聊天”，不能可靠写入结构化数据；
5. 数据难以导出和迁移；
6. 离线和云同步经常无法兼顾。

## 5. 核心价值

Lifly 的核心价值是：

```text
自然语言输入 → MCP 工具调用 → 结构化生活数据 → 本地可用 → 云端同步 → 可审计/可撤销/可导出
```

用户可以输入：

```text
今天中午食堂花了 18，晚上 8 点提醒我改 Lifly 登录页，顺便记一下今天有点累。
```

系统自动拆解为：

- 一条餐饮账单；
- 一个任务提醒；
- 一条日记/备忘。

## 6. MVP 功能

MVP 只包括：

- 备忘录/日记/文档；
- 附件；
- 记账；
- CSV 导入；
- 任务提醒；
- 本地离线；
- 云端同步；
- 云端 MCP；
- Windows 本地 MCP；
- 审计日志；
- 回收站；
- 基础导出。

## 7. 暂不做功能

第一版明确不做：

- 完整日历视图；
- 多用户/家庭账本；
- Android 通知监听；
- 飞书/Notion 双向同步；
- 完整复式记账；
- 复杂图表报表；
- 端到端加密；
- 社交功能；
- 多工作区协作；
- 飞书式块编辑器。

## 8. 成功指标

MVP 的成功不以 UI 丰富度衡量，而以闭环是否可用衡量。

关键指标：

- 用户能否在 5 秒内完成一条自然语言记录；
- 混合输入能否稳定拆解为多个动作；
- 离线创建数据后能否稳定同步；
- CSV 导入能否预览、去重、回滚；
- AI 写入是否全部可追踪、可撤销；
- Windows + Android 数据是否一致；
- MCP Client 是否能可靠创建/查询/修改数据。
