# Lifly v0.5.x Assets & Import/Export 全量开发计划

## 1. 版本定位

v0.5.x 的目标是让 Lifly 支持真实生活数据迁入和附件管理，形成“记录 + 资料 + 历史数据”的完整输入闭环。

v0.4 已经完成 AI 写入、确认、撤销、审计和诊断。v0.5 不继续扩大 AI 写入能力，而是补齐 asset metadata、内部文件上传体验、外部链接引用、CSV 导入预览/提交/回滚和基础导出。

稳定起点：

```text
v0.4.11
```

完成分支：

```text
develop/v0.5.7
```

发布门禁文档：

```text
docs/64-v0.5-release-gate.md
```

## 2. 版本目标

```text
附件 metadata 稳定
内部文件上传 URL 可用
外部链接注册可用
memo 可引用 asset
CSV 导入走 preview / commit
支付宝 / 微信账单可解析
导入批次可回滚
核心数据可导出
导入、导出、附件写入都进入 audit_logs
```

## 3. v0.5 明确不做

```text
不做复杂 OCR
不做云盘深度同步
不做自动读取用户系统文件
不做未经确认的大规模导入
不做多人共享附件库
不做端到端加密
不做完整商业化文件管理
```
