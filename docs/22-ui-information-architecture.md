# 22. UI 与信息架构

## 1. 设计原则

Lifily 的 UI 不是复杂工作台，而是快速记录和修正数据的工具。

原则：

- 快速输入优先；
- 今日视图优先；
- 搜索优先；
- 手动编辑要简单；
- AI 结果可预览、可撤销；
- 同步状态透明。

## 2. 一级导航

MVP 建议：

```text
今日
记录
账单
任务
搜索
设置
```

## 3. 今日页

展示：

- 今日任务；
- 今日提醒；
- 今日账单摘要；
- 今日备忘/日记；
- 快速输入框；
- 同步状态。

## 4. 快速记录页

核心输入框：

```text
输入一句话，例如：中午食堂18，晚上8点提醒我改页面
```

按钮：

- AI 解析；
- 直接保存为备忘；
- 手动选择类型。

AI 解析后展示 action cards：

- 账单卡；
- 任务卡；
- 备忘卡。

用户可以删除某个 action，再提交。

## 5. 备忘录页

列表维度：

- 全部；
- 备忘；
- 日记；
- 摘录；
- 文档；
- 标签；
- 日期。

编辑页：

- Markdown；
- 附件；
- 预览；
- 标签；
- 类型选择。

## 6. 账单页

视图：

- 今日；
- 本周；
- 本月；
- 分类；
- 商户；
- 导入批次。

新建账单：

- 金额；
- 分类；
- 账户；
- 商户；
- 时间；
- 备注。

## 7. 任务页

视图：

- 今日；
- 待办；
- 已完成；
- 逾期；
- 全部。

任务卡：

- 标题；
- 提醒时间；
- 截止时间；
- 完成按钮；
- 来源标记，手动/AI。

## 8. 搜索页

统一搜索：

- 备忘录；
- 账单；
- 任务；
- 附件；
- 导入批次，后续。

## 9. 回收站

分为：

- AI 回收站；
- 普通回收站。

AI 回收站用于展示 AI 删除/隐藏的数据，用户可恢复或确认删除。
