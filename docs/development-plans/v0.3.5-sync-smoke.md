# v0.3.5 同步 smoke 验证

## 目的

验证 v0.3 云同步 MVP 的最小后端闭环：凭据接口、同步推送接口、普通 REST 详情读回。

## 前置条件

后端 API 需要先启动在本机默认端口：

```bash
bash scripts/dev-start.sh
```

如后端地址不是默认值，可设置：

```bash
export LIFLY_API_BASE_URL=http://localhost:8310
```

## 执行

```bash
bash scripts/smoke-sync-v0.3.sh
```

通过时应看到：

```text
[PASS] health
[PASS] sync_credentials
[PASS] sync_push memo/task/expense
[PASS] memo_readback
[PASS] task_readback
[PASS] expense_readback
[PASS] sync_push stale revision -> skipped
```

## 验证范围

脚本会构造一组等价于 Flutter PowerSync uploadData 的 sync push payload：

```text
memo upsert
任务 upsert
记账 upsert
```

然后确认：

```text
后端返回 applied=3 / skipped=0
普通 REST 详情接口可以读回刚刚同步的数据
重复提交同一 revision 会返回 stale_revision skipped
```

## 不覆盖范围

本脚本不启动 Flutter，也不真实连接 PowerSync 服务。Flutter 侧连接入口由 Settings 页面手动验证：

```text
设置 -> 同步凭据 / PowerSync -> 连接 PowerSync
```

连接后再进行本地 memo/task/expense 写入，可在同一卡片中刷新查看 uploadData 上传诊断。
