# v0.6.6 导入导出体验收口与发布门禁

## 平台范围

- Flutter 客户端：`apps/client_flutter`
- 服务端：不新增业务接口，仅复用 v0.5 / v0.6 已有 import-export API
- 小程序：不在本轮范围内

## 本轮目标

v0.6 已完成导入与导出的主要客户端链路，本轮只做发布前收口：统一入口、明确 Cloud API / Local Core 边界、补齐回归测试与手动验收清单，避免继续扩大功能面。

## 已收口入口

设置页 `数据管理` 分组统一为三条主链路：

1. `账单导入`
   - 上传微信 / 支付宝 / 通用 CSV / XLSX 文件
   - 先生成预览，不直接写入记账流水
2. `导入批次`
   - 查看历史导入批次
   - 继续检查预览或追踪提交结果
3. `数据导出`
   - 先生成导出预览
   - 确认文件名、大小、checksum、counts 后下载导出流

## 模式边界

### Cloud API

必须可用：

- 账单导入入口
- 导入批次入口
- 数据导出入口
- 导入预览上传
- 导入预览详情
- 导入提交
- 批次筛选与分页
- 导出元数据预览
- 导出文件下载

### Local Core

必须明确禁用或提示：

- 设置页数据管理入口提示导入导出需要 Cloud API
- 账单导入页提示导入预览需要 Cloud API
- 数据导出页提示导出需要 Cloud API
- 不应触发上传、提交、导出等 Cloud API 写入/下载操作

## 手动验收清单

### 设置页

- 进入 `设置`
- 找到 `数据管理`
- Cloud API 模式下确认提示为可导入、提交、追踪批次并导出数据
- 入口顺序应为：`账单导入` -> `导入批次` -> `数据导出`

### 账单导入

- 进入 `设置 -> 数据管理 -> 账单导入`
- 选择来源：自动识别 / 微信支付 / 支付宝 / 通用 CSV
- 上传微信或支付宝流水文件
- 确认上传后只生成预览，不直接写入流水
- 点击 `查看完整预览`

### 导入预览

- 确认批次摘要显示 batch id、文件名、状态、总行数、有效行、重复行
- 切换状态筛选：全部 / 待导入 / 已忽略 / 错误 / 重复 / 已导入
- 展开预览行，确认金额、方向、商户、时间、备注、原因可读
- 多于一页时点击 `加载更多`
- 点击 `提交导入`，确认出现二次确认
- 取消提交不应写入
- 确认提交后展示 imported / duplicates / errors / skipped

### 导入批次

- 进入 `设置 -> 数据管理 -> 导入批次`
- 确认列表加载成功
- 切换筛选：全部 / 预览中 / 已提交 / 已回滚
- 点击任一批次进入预览详情
- 多于一页时点击 `加载更多`

### 数据导出

- 进入 `设置 -> 数据管理 -> 数据导出`
- 切换导出范围：全部数据 / 记账流水 / 备忘 / 任务 / 附件
- 点击 `生成导出预览`
- 确认显示 filename、size、checksum、contract、counts、preview
- 点击 `下载导出文件`
- 确认显示下载字节数、header 文件名、media type、checksum、contract

### Local Core 边界

用 Local Core 模式启动：

```bash
cd /home/Akira/Projects/lifly/apps/client_flutter
flutter run -d linux \
  --dart-define=LIFLY_DATA_MODE=local \
  --dart-define=LIFLY_API_BASE_URL=http://127.0.0.1:8310/api/v1
```

确认：

- 设置页数据管理分组显示 Local Core 边界提示
- 数据管理下三条入口显示锁定状态
- 账单导入页和数据导出页的操作按钮不可触发 Cloud API 动作

## 发布门禁

发布 v0.6 前必须满足：

- `flutter analyze` 无问题
- `flutter test --reporter=compact` 全量通过
- `git diff --check` 无输出
- Flutter 客户端新增/修改文件未超过项目行数限制
- Cloud API 模式完成导入导出主链路手动验收
- Local Core 模式完成边界提示和禁用状态手动验收
