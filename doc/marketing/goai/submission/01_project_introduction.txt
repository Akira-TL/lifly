Lifly（Life + Fly）想解决的，不是“怎样更认真地管理生活”，而是让这些管理动作尽量消失。消费后不用再逐笔记账，临时想到的事也不用切到日历里一格一格安排。用户可以直接说一句话、发付款截图、导入支付宝或微信账单，也可以让自己已经在用的 Hermes、OpenClaw 等 Agent 通过 MCP 调用 Lifly。Lifly 会把这些信息整理成备忘、账单和任务候选，正式写入前保留确认、去重、审计和撤销。用户自己的电脑还可以成为 Personal Compute Node，在本机通过 Ollama 和 Local MCP 处理任务；需要云 AI 时，只发送用户本次明确授权的最小上下文。项目目前已经打通 Web、Android、Desktop、Cloud/Local MCP、E2EE Sync 和 Compute Node 的工程链路。源码计划采用非商业可用许可证：允许 fork、修改和非商业分发，商业使用需另行授权。
