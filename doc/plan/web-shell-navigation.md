# v0.8.1 Web 极简 Shell 与全局导航

状态：开发中，等待 Web 人工视觉验收。

平台范围：Flutter Web 为首要验收平台；共享桌面端宽屏 Shell；手机端保持现有五入口结构并做回归。

## 目标

把 v0.8.0 已建立的主题与多端布局地基，落成可承载后续首页、备忘、记账、任务和 AI 页面改造的 Web 产品外壳。

默认 Lifly Core 继续优先保证启动速度和实用性。Shell 只负责全局导航、全局入口、内容边界和键鼠交互，不在外壳中复制业务页面状态或长期产品规则。

## 当前视觉检查点

- Web dashboard 使用可展开的 248px 左侧栏；
- 展示 Lifly 品牌和“生活数据中心”说明；
- 五个核心入口保持：首页、备忘、AI、记账、任务；
- 增加全局搜索和 AI 快速记录；
- 增加附件与设置/诊断入口；
- 支持侧栏折叠，并在设备本地保存折叠状态；
- 支持 `Ctrl+K` 打开搜索，`Ctrl+N` 进入 AI 快速记录；
- 内容区最大宽度为 1600px，超宽屏保留稳定留白；
- 桌面 compact 继续使用紧凑侧栏；
- 手机端五入口和 48px 触控边界保持不变。

## 后续收口内容

- 根据人工视觉反馈调整侧栏密度、间距、品牌区和选中态；
- 增加导入导出、同步状态和诊断的全局管理入口组织方式；
- 提取共享 Loading、Empty、Error、Offline 页面状态组件；
- 检查浏览器刷新、路由返回和主题切换时的 Shell 状态；
- 增加 Web Shell 构建与键盘交互发布门禁；
- 完成正式文档回写后删除本计划文件。

## 验收

```text
Web 宽屏能清楚区分全局导航和业务内容
搜索、AI 快速记录、附件和设置入口可达
侧栏折叠状态跨重建保留
主题切换不重建 Shell 业务服务和当前页面
桌面 compact 与手机端导航无回归
flutter analyze / flutter test / flutter build web 通过
```
