# 26. v0.1 架构冻结说明

## 1. 冻结状态

LifeCore v0.1 架构冻结。AI agent 可以在冻结范围内实现功能，但不得擅自改变技术栈、模块边界、同步策略和 MCP 策略。

## 2. v0.1 只做

```text
备忘录 / 日记 / 文档
记账
任务提醒
附件
CSV 导入
云端 MCP
Windows 本地 MCP
本地离线
云端同步
审计与回收站
```

## 3. v0.1 不做

```text
完整日历 UI
多用户/家庭账本
Android 通知监听
飞书/Notion 双向同步
完整复式记账
端到端加密
社交功能
团队协作
复杂块编辑器
```

## 4. 技术栈冻结

客户端：

```text
Flutter
Windows + Android first
PowerSync SQLite
Markdown + 附件卡片
```

后端：

```text
FastAPI
PostgreSQL
PowerSync
Redis
Object Storage: MinIO dev / R2 or S3 prod
```

MCP：

```text
Cloud MCP: TypeScript + HTTP
Local MCP: TypeScript + stdio, Windows only
Cloud/Local 共用 tool schema
```

Monorepo：

```text
pnpm workspace 管理 TypeScript packages/services
Turborepo 编排 TypeScript 任务
uv 管理 Python/FastAPI
Flutter 工程独立在 apps/client_flutter
Docker Compose 管理本地基础设施
```

## 5. 数据边界

附件二进制不进入 PostgreSQL，不走 PowerSync。数据库只保存 metadata。

所有创建、修改、删除、导入、导出、MCP 写操作必须写 audit_logs。

CSV 导入必须走：

```text
import_batch → import_rows → preview → commit → ledger_transactions
```

AI 删除：

```text
active → ai_trashed
```

用户删除：

```text
active → user_trashed → purged
```
